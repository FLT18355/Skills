# Contributing to Skills

Thank you for your interest in contributing! This repository contains skills for various coding agents (Pi, Opencode, Cline, etc.). Your contributions help make these tools better for everyone.

## Ways to Contribute

- **Report bugs** - Found an issue? Open a bug report.
- **Suggest features** - Have an idea? Open a feature request.
- **Improve documentation** - Fix typos, add examples, clarify explanations.
- **Add new skills** - Create skills for other coding agents or extend existing ones.
- **Fix bugs** - Submit pull requests for issues you've identified.

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Run any tests/linters if available
5. Commit with clear messages
6. Push to your fork
7. Open a Pull Request

## Pull Request Guidelines

- Keep PRs focused on a single change
- Write clear commit messages
- Update documentation if needed
- Ensure your code follows the existing style
- Link related issues in the PR description

## Skill Development

If you're adding a new skill:

1. Create a new directory under `skills/` with a descriptive name
2. Include a `SKILL.md` file with:
   - Skill name and description
   - Installation instructions
   - Usage examples
   - Configuration options
3. Follow the existing skill structure
4. Test your skill thoroughly

## Code Style

- Use consistent indentation (2 spaces for most files)
- Write meaningful variable/function names
- Add comments for complex logic
- Keep functions small and focused

## Reporting Issues

When reporting issues, please include:

- Clear title and description
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, agent version, etc.)
- Screenshots if applicable

## Community

- Be respectful and inclusive
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md)
- Help others in discussions and issues
